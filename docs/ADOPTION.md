# Что мы изучили на GitHub и что взяли

Изучены открытые проекты «второго мозга». Почти все они устроены иначе, чем наш: в них агент (обычно Claude Code) работает на компьютере или VPS с прямым доступом к папке хранилища. У нас хранилище лежит в iCloud на iPhone, сервер до него не дотягивается, а ИИ это DeepSeek. Поэтому код мы не копируем, а перенимаем механизмы.

| Проект (лицензия) | Как устроен | Что взяли | Что не подошло |
|---|---|---|---|
| [smixs/agent-second-brain](https://github.com/smixs/agent-second-brain) (MIT) | Telegram → голос (Deepgram) → долгоживущая сессия Claude Code в tmux на VPS → vault; вечерняя обработка в 21:00, затухание памяти по формуле, самодиагностика | Вечерний проход и отчёт; голос из Telegram; «случайный возврат» старых карточек → блок «Из прошлого»; проверка здоровья базы; один `schema` как источник типов (у нас `app/schema.py`) | Нужны VPS, подписка Claude и синхронизация vault на сервер; агент с доступом к диску |
| [eugeniughelbur/obsidian-second-brain](https://github.com/eugeniughelbur/obsidian-second-brain) (MIT) | Набор из ~45 команд для Claude Code; агенты утро 8:00, ночь 22:00, пятница, воскресная проверка; гибридный семантический поиск (эмбеддинги + ключевые слова) | Расписание (утро, неделя, проверка); `/catchup` из Telegram (наша очередь `/pending`); `health` (дубли, сироты, зависшее); `merge` только с предпросмотром и без удаления (принцип); `recurring` в планах | Семантический поиск требует эмбеддингов: отложен, см. ниже |
| [itechmeat/open-second-brain](https://github.com/itechmeat/open-second-brain) (MIT) | Ночной «dream pass» без ИИ: счётчики и атомарные операции превращают повторяющиеся поправки в подтверждённые предпочтения | Принцип «изменения базы делает детерминированный код, а не ИИ»; всё в обычных файлах; отчёт «данных нет» вместо выдуманных цифр | Модель «предпочтений агента» нам не нужна |

| [khoj-ai/khoj](https://github.com/khoj-ai/khoj) (AGPL-3.0) | Готовое приложение: семантический поиск, чат с заметками, автоматизации | Идея запланированных автоматизаций | Лицензия AGPL и тяжёлый стек (Django, Postgres): не вписывается в маленький сервис |

## Сделано по итогам

1. Утро, неделя и вечер: бот сам пишет (часть 12 README).
2. Напоминания в срок с кнопками «через час», «завтра», «ок».
3. «Из прошлого» и `/remember`: старые идеи и хотелки возвращаются.
4. `/health`: дубли, неразобранное, зависшие дела, карточки без роли.
5. Голос в Telegram (часть 10).
6. Интервью: отказы не пишутся, извлекаются сущности, сырые ответы собираются в одну заметку блока.

## Не сделано и почему

- **Семантический поиск (эмбеддинги).** По отчёту obsidian-second-brain, для не-английских запросов он поднимает полноту поиска с 13% до 63%. Для русских формулировок «что я обещал про замок?» это заметно. Нужен ключ сервиса эмбеддингов (OpenAI, Jina, Voyage и т.п.) и хранение векторов в срезе. Следующий шаг, если захочешь.
- **Самоперезаписывающиеся заметки и автослияние дублей.** Опасно без предпросмотра. Сейчас только `/health` показывает дубли; слияние добавим с предпросмотром и без удаления.
- **Запуск agent-second-brain целиком.** Возможен, но потребует VPS, платную подписку Claude Code и перенос vault с iCloud на сервер. Это другой проект, а не доработка нашего.
