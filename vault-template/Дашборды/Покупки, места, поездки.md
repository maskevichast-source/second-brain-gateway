# Покупки, места, поездки

Что хочу купить, куда сходить и поехать.

## Хочу купить

```dataview
TABLE kind AS "Вид", price AS "Цена", where_to_buy AS "Где", deadline AS "К сроку"
WHERE type = "product" AND (status = "хочу" OR status = "в-процессе")
SORT created DESC
```

## Места, куда хочу сходить

```dataview
TABLE kind AS "Вид", city AS "Город", recommended_by AS "Посоветовал", summary AS "Суть"
WHERE type = "place" AND status = "хочу"
SORT city ASC
```

## Поездки

```dataview
TABLE destination AS "Куда", date_from AS "С", date_to AS "По", status AS "Статус"
WHERE type = "trip" AND status != "завершена" AND status != "отменена"
SORT date_from ASC
```
