# Люди

Карточки людей и всё, что с ними связано. Подробные карточки позже будет создавать агент на ноутбуке.

## Все карточки

```dataview
TABLE company AS "Компания", role AS "Роль", phones AS "Телефоны", birthday AS "День рождения"
WHERE type = "person"
SORT file.name ASC
```

## Недавние контакты

```dataview
TABLE people AS "С кем", kind AS "Вид", topic AS "О чём", follow_up AS "Что дальше"
WHERE type = "interaction"
SORT created DESC
LIMIT 20
```

## Идеи подарков

```dataview
TABLE for_whom AS "Кому", price AS "Цена", summary AS "Суть"
WHERE type = "product" AND kind = "подарок" AND status != "готово"
```
