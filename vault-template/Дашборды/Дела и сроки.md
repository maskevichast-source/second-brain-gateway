# Дела и сроки

Открытые дела, ожидания и ближайшие события.

## Открытые дела (по сроку)

```dataview
TABLE due AS "Срок", priority AS "Приоритет", people AS "Кто", summary AS "Суть"
WHERE type = "task" AND (status = "открыто" OR status = "в-работе")
SORT due ASC
```

## Жду от других

```dataview
TABLE people AS "Кто", due AS "Срок", summary AS "Суть"
WHERE type = "task" AND status = "ждёт"
SORT created ASC
```

## Ближайшие события

```dataview
TABLE event_at AS "Когда", location AS "Где", summary AS "Суть"
WHERE type = "event" AND status = "запланировано" AND event_at >= date(today)
SORT event_at ASC
```

## Проекты в работе

```dataview
TABLE deadline AS "Срок", next_action AS "Следующий шаг"
WHERE type = "project" AND (status = "открыто" OR status = "в-работе" OR status = "ждёт")
```

## Цели

```dataview
TABLE horizon AS "Горизонт", deadline AS "Срок", metric AS "Мера"
WHERE type = "goal" AND status = "активна"
```
