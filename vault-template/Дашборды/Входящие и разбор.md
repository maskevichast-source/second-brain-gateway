# Входящие и разбор

Свежие заметки, которые ещё не просмотрены. Просмотрел — поменяй `stage` на `processed`.

## Новые (inbox)

```dataview
TABLE type AS "Тип", area AS "Сфера", summary AS "Суть", created AS "Создано"
WHERE stage = "inbox"
SORT created DESC
```

## ИИ был не уверен или не работал (confidence < 0.6)

```dataview
TABLE type AS "Тип", confidence AS "Уверенность", summary AS "Суть"
WHERE stage = "inbox" AND confidence < 0.6
SORT created DESC
```

## Не разобранные закладки

```dataview
TABLE source_url AS "Ссылка", created AS "Создано"
WHERE type = "bookmark" AND status = "не-разобрано"
SORT created DESC
```
