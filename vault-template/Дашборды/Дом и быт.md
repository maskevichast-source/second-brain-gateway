# Дом и быт

Уход по расписанию, ремонт, гарантии, документы.

## Что требует ухода скоро

```dataview
TABLE item AS "Что", next_due AS "Когда", schedule AS "Расписание"
WHERE type = "home" AND next_due
SORT next_due ASC
```

## Открытые домашние дела

```dataview
TABLE kind AS "Вид", contractor AS "Подрядчик", summary AS "Суть"
WHERE type = "home" AND (status = "открыто" OR status = "в-работе" OR status = "ждёт")
```

## Гарантии

```dataview
TABLE item AS "Что", warranty_until AS "До"
WHERE type = "home" AND warranty_until
SORT warranty_until ASC
```

## Документы, срок которых истекает

```dataview
TABLE kind AS "Вид", counterparty AS "С кем", valid_until AS "До"
WHERE type = "document" AND valid_until
SORT valid_until ASC
```

## Споры и процессы

```dataview
TABLE counterparty AS "С кем", next_step AS "Следующий шаг", deadline AS "Срок"
WHERE type = "case" AND status != "сделано" AND status != "отменено"
```
