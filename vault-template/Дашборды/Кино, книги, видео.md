# Кино, книги, видео

Всё, что хочу посмотреть, прочитать или послушать.

## Фильмы и сериалы — хочу посмотреть

```dataview
TABLE kind AS "Вид", year AS "Год", recommended_by AS "Посоветовал", summary AS "Суть", created AS "Записано"
WHERE type = "media" AND status = "хочу" AND contains(list("фильм","сериал","мультфильм","аниме"), kind)
SORT created DESC
```

## Книги и аудиокниги — хочу

```dataview
TABLE kind AS "Вид", creator AS "Автор", recommended_by AS "Посоветовал", summary AS "Суть"
WHERE type = "media" AND status = "хочу" AND contains(list("книга","аудиокнига"), kind)
SORT created DESC
```

## Видео, статьи, подкасты, курсы — хочу

```dataview
TABLE kind AS "Вид", source_url AS "Ссылка", summary AS "Суть"
WHERE type = "media" AND status = "хочу" AND contains(list("видео","статья","подкаст","курс"), kind)
SORT created DESC
```

## Сейчас в процессе

```dataview
TABLE kind AS "Вид", progress AS "Прогресс", summary AS "Суть"
WHERE type = "media" AND status = "в-процессе"
```

## Недавно закончено

```dataview
TABLE kind AS "Вид", rating AS "Оценка", finished_at AS "Когда"
WHERE type = "media" AND status = "готово"
SORT finished_at DESC
LIMIT 20
```
