# Мысли и решения

Идеи, выводы, решения и открытые вопросы.

## Идеи в работе

```dataview
TABLE next_step AS "Следующий шаг", summary AS "Суть"
WHERE type = "idea" AND (status = "сырая" OR status = "прорабатываю")
SORT created DESC
```

## Решения, которые пора пересмотреть

```dataview
TABLE review_at AS "Когда", reasons AS "Причины"
WHERE type = "decision" AND (status = "пересмотреть" OR (review_at AND review_at <= date(today)))
```

## Открытые вопросы

```dataview
TABLE asked_to AS "Кому", summary AS "Суть"
WHERE type = "question" AND status = "открыт"
```
